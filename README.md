# Airbnb A/B Testing Analysis (SQL + Dashboard)

## Project Overview
This project uses the Airbnb Open Data dataset from Kaggle to perform an A/B testing-style analysis by comparing two groups of listings (control vs treatment).  
The goal is to calculate lift, explore key metrics, and visualize results in a simple interactive dashboard.

## Dataset
Source: Airbnb Open Data (Kaggle)  
https://www.kaggle.com/datasets/arianazmoudeh/airbnbopendata

## Objectives
- Clean and preprocess Airbnb listing data
- Define control and treatment groups (simulated experiment setup)
- Use SQL to compute group metrics and lift
- Perform statistical testing to evaluate significance
- Build a simple dashboard to visualize insights

## Tools & Tech Stack
- Python (Pandas, NumPy, SciPy)
- SQL (SQLite / PostgreSQL)
- Streamlit (dashboard)
- Matplotlib / Seaborn (visualizations)
